Expose a local application

Share any locally running app on a specific port — no port forwarding or static IP needed. Others reach it with the generated link. Looking to send a folder instead? Use the Share a folder tab — it needs no port.

⚠️ Public mode — no encryption. Anyone with the key can connect, and traffic is plaintext. Only use this for services you'd expose publicly anyway.

Connect to a tunnel

Paste the link you were sent — it starts with hs://. Private links (hs://s000…) are encrypted and public ones (hs://0000…) are not; which one you have is detected automatically.

⚠️ Public connection string (`hs://0000…`). This tunnel is unencrypted — anyone with the key can connect. Only connect to services you trust.

On this phone: permanent tunnels only restart after a reboot if the app is allowed to start automatically. Check Settings → Apps → holesail-gui → Auto-launch (label varies by OEM — on OnePlus/OxygenOS it's under "Other permissions") and enable it. Also use the localhost URL on each card — some Android browsers refuse 127.0.0.1.

Node.js required

This build runs its tunnel engine with the bundled runtime, so this only happens on a source install without it. Install a Node.js runtime, then retry — or restart the app (that also refreshes PATH).
